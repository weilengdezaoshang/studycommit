# StudyCommit React Native 开发路线图

## 1. 职责边界

移动端负责随时学习与执行：

- 学习计时和后台恢复；
- 快速记录；
- 轻量笔记阅读/编辑；
- 高频复习；
- 知识地图浏览和选择式关系建立；
- 本地 SQLite 与离线同步。

移动端第一阶段不负责：

- 直接操作 Git 仓库；
- 自由拖线和复杂地图整理；
- 桌面级 Markdown 深度编辑；
- 大批量内容管理。

## 2. 当前状态

已经具备：

- Expo SDK 57 + React Native 工程；
- iOS/Android 启动脚本；
- 应用外层、语义主题和安全区；
- 顶层渲染错误兜底；
- Jest + React Native Testing Library 测试基座；
- TypeScript 检查；
- 移动高保真原型。

尚未具备导航、本地数据库、后台计时和业务页面。

## 3. P0-A：移动工程基座

### RN-000 应用外层与测试体系

状态：已完成。

- 应用启动入口与 Provider 分层；
- 安全区、深浅色主题和状态栏；
- 顶层渲染错误兜底；
- Jest、jest-expo 与 React Native Testing Library；
- 单元测试、组件测试和根应用集成测试；
- 作为 RN-001 导航结构的前置任务。

### RN-001 导航结构

状态：已完成。

底部模块：

- 今天；
- 专题；
- 记录；
- 复习；

“我的”通过顶部头像进入，不占用底部导航位。

规则：底部切换不清空模块状态；系统返回先关闭键盘、菜单、抽屉、弹窗。

### RN-002 设计系统

状态：已完成自动化实现与双平台 bundle 验证；发布前执行真机可访问性矩阵。

- 与桌面共享 design tokens；
- 保持移动端独立布局；
- iOS 44pt / Android 48dp 最小触控区；
- 安全区；
- 字体放大；
- 浅色/深色；
- Loading、Empty、Error、Offline。

### RN-003 数据访问层

- 领域类型和 Zod schema 共享；
- Repository 接口；
- API client；
- 错误归一化；
- 网络状态；
- 不让页面直接依赖原始 API DTO。

### RN-004 Topic 基础页面

- 专题列表；
- 当前专题；
- 创建/轻量编辑；
- 离线缓存；
- 空状态和重试；
- 对接 Topic API。

## 4. P0-B：移动最小学习闭环

### RN-101 今天页面

- 当前会话；
- 最近专题；
- 今日记录；
- 到期复习；
- 快速开始。

### RN-102 开始学习

- 选择专题；
- 输入目标；
- 30 秒内开始；
- 输入控件避开键盘和安全区。

### RN-103 计时和后台恢复

- running、paused、completed；
- 使用时间戳计算；
- AppState 前后台切换恢复；
- 进程重启恢复；
- 系统时间异常处理；
- 同一设备防止重复会话。

第一阶段不承诺系统强杀后持续执行 JavaScript 计时；恢复时根据持久化时间戳重建状态。

### RN-104 快速记录

- 计时中快速输入；
- 关联当前 Topic/Session；
- 保存后不打断计时；
- 离线可用。

### RN-105 学习收尾

- 收获、问题、下一步；
- 保存 Learning Log；
- 保存失败保留输入；
- 支持稍后整理草稿。

验收路径：

```text
选择专题 → 开始计时 → 切后台 → 恢复 → 完成 → 收尾 → 记录可查询
```

## 6. P0-D：本地优先和同步

### RN-301 expo-sqlite

- 本地 schema 和迁移；
- 核心实体持久化；
- 应用启动恢复；
- Repository 实现；
- 敏感 Token 使用安全存储，不放普通 SQLite。

### RN-302 Outbox

- 本地操作先成功；
- 写入待同步事件；
- 网络恢复自动重试；
- 退避和失败状态；
- 幂等键。

### RN-303 Pull 和冲突

- 游标拉取；
- 前台启动/网络恢复触发；
- tombstone；
- 正文冲突不覆盖；
- 冲突副本和选择界面；
- 地图坐标冲突不影响 Note。

### RN-304 离线体验

- 离线状态非阻塞；
- 核心计时、记录、笔记、复习可用；
- 显示上次同步和待同步数量；
- 用户可手动重试。

## 10. React Native 验收矩阵

设备与布局：

- 小屏手机；
- 大屏手机；
- iOS 与 Android；
- 横屏和安全区；
- 最大系统字体；
- 浅色/深色；
- 减少动态效果。

行为：

- 后台/前台计时恢复；
- 进程重启恢复；
- 键盘不遮挡主要操作；
- 系统返回层级正确；
- 导航切换保留状态；
- 离线完成核心流程；
- 网络恢复后无重复数据；
- 屏幕阅读标签完整。
