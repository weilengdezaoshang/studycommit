摘要

Fabric 通过 Render、Commit 和 Mount 三个阶段，将 React 更新应用到原生视图。

渲染阶段

Fabric 是 React Native 新架构中的渲染系统。它将 React 的更新转换为 Shadow Tree 的变化。

  • Render：创建新的 Shadow Tree。
  • Commit：完成布局并提交新树。
  • Mount：应用到宿主平台视图。
