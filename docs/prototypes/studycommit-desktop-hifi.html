笔记详情

React Native / 新架构

Fabric 是 React Native 新架构中的渲染系统。它将渲染器的核心部分迁移到 C++，使多平台可以共享更多实现，并允许渲染流程与 React 并发能力更紧密地协作。

渲染阶段

一次更新会经历 Render、Commit 和 Mount 三个阶段。Render 阶段创建新的 Shadow Tree；Commit 阶段完成布局与一致性检查；Mount 阶段把差异应用到宿主平台视图。

需要继续验证

阅读 ShadowTree::commit 的重试逻辑，确认并发更新发生冲突时如何重新计算。
