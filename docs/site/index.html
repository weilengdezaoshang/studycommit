WHY STUDYCOMMIT

学习不是收集更多，
而是留下更重要的。

三个动作构成一次完整的学习回路：捕捉、整理、继续。

01 / CAPTURE

想到什么，
先放进纸页。

灵感像咖啡一样涌出来——先接住再说。没有标题、分类和总结的门槛，保留当下的原话，给未来的自己留一条线索。

  • 打开即写，不要求先想好结构
  • 原话保存，不做自动改写
02 / ORGANIZE

整理发生在之后。

像图里这样坐下来，把散落的记录一件件放回你亲自创建的主题，知识结构不被自动替你决定。

  • 自建主题，自由移动纸页
  • 结构随理解演进，不锁死
03 / CONTINUE

问题会带你继续。

带着还没弄懂的问题回到书桌，从真实问题开始下一次学习，并保留理解前后的变化。

  • 未解决问题沉淀成线索
  • Agent 围绕原记录追问解释
PRODUCT

在桌面整理，
在移动端捕捉。

两端共享同一套纸页语义，适配不同的学习时刻。

DESKTOP

看见今天留下的内容，并把它们放回主题。

纸页、主题和问题在同一个界面里流动，每条记录都能回到它应该在的地方。

FEATURES

把学习过程，
拆成几个简单动作。

每个功能都服务于记录、整理和继续理解，不制造额外的任务感。

01 / 快速记录

随手写下知识、想法和问题

不要求标题、分类或总结，先把当下真正想到的内容保存下来。

02 / 主题整理

把纸页放回你的主题

支持创建主题、移动记录和持续维护自己的知识结构。

03 / 问题追踪

标记还没弄懂的地方

从未解决的问题继续学习，并保留理解前后的变化。

“不要求现在就懂，
但要让未来的自己找得到。”
StudyCommit 的设计原则
