# StudyCommit GitHub Pages 官网

V3 雾蓝手绘官网。`docs/index.html` 跳转到此目录，现有 GitHub Pages 工作流发布整个 `docs`，不需要前端打包。应用侧边栏及业务页面不在本次改动范围。

## 文件与素材

- `index.html`：可访问的页面区块、三步流程、示例产品界面和命令代码。
- `styles.css`：桌面/平板/手机布局，纸边、折角、笔触、焦点及减少动态规则。
- `site.js`：一次性入场、导航开合、复制成功/失败反馈。正文默认可见，不依赖脚本才能阅读。
- `tokens.css`：由共享 `packages/design-tokens` 生成，禁止手工复制修改公共颜色和间距。
- `assets/peeking-cat.png`：复用 V7 R100 探头猫，独立装饰图。
- `assets/fonts/StudyCommitCasual-UI.woff2`：复用现有小赖界面子集；OFL 许可证随字体保留，缺字回退系统字体。许可证见 `assets/fonts/OFL.txt`。

本发布目录使用开发分支共享设计变量的已生成快照，无需构建。公共设计变量变化后，在含有雾蓝主题的开发分支中使用 Node.js 24 执行以下命令，再同步生成文件：

```bash
node scripts/generate-site-tokens.mjs
```

本地预览：

```bash
python3 -m http.server 8770 --bind 127.0.0.1 --directory docs
```

打开 `http://127.0.0.1:8770/site/`。发布仍通过现有 `.github/workflows/deploy-site.yml`；推送 main 后自动发布。

## 设计与动态

采用 V3 雾蓝手绘设计。字体与图片生成字形有差异；内容保持 HTML，产品区是明确标注的静态示例组件，不伪装成用户账户或发布版本截图。日期组内没有时间轴。热力为无日期的概念示意，不提供虚构统计或可交互假数据。

| 区域 | 过渡 | 触发与边界 |
| --- | --- | --- |
| 导航 / 页脚 | 下划线150ms | hover / focus；锚点原生平滑滚动，固定高度 |
| 首屏笔触 | 从左向右420ms | 首次入场；不支持伪元素动画时保留静态笔触 |
| 首屏便笺 | 上移12px、淡入420ms，交错60ms | 素材已就绪且页面在顶部时播放一次；慢素材直接呈现，不阻塞正文 |
| 主次按钮 | 色彩与箭头150ms，按下立即下移1px | 快速操作不排队 |
| 产品预览 | 整组上移16px、淡入420ms | 15%进入视口，播放一次 |
| 三步流程 | 上移8px、淡入240ms，交错80ms | 箭头随后绘制240ms；手机保持向下箭头 |
| 复制命令 | 成功状态150ms淡入 | clipboard成功后才显示已复制；失败可重试或手动选取 |
| 热力与回看 | 静态 | 概念数据，不生成假 tooltip 或数字动画 |

减少动态模式取消入场和空间位移，锚点立即定位；运行中改变偏好会取消现有动画。动画接口缺失不会阻断菜单、代码复制等功能。无 JavaScript 时所有内容直接可见，移动原生 details 导航仍可展开，复制按钮隐藏，代码可以手选。

## 验证

本轮在隔离 Chromium 浏览器、本机 HTTP 服务下检查：

- 1440、768、390、320px 宽度均无页面横向溢出。
- 图片加载成功，无页面脚本异常或资源请求失败。
- 移动导航展开、Esc 关闭与焦点恢复、点击锚点后关闭。
- 复制命令的成功内容与拒绝权限后的失败反馈。
- 减少动态模式无活动动画，滚动为 auto。
- 禁用 JavaScript 后标题、流程、命令正常可见。
- 页内导航锚点全部有效。
- JavaScript ESLint、语法检查、共享Token再生成一致性和 diff 空白检查。

截图与检查结果保留在开发工作区。外部 GitHub 链接采用仓库现有地址，未把本地验证当成线上发布验收。
